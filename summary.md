## Current Core Features

- Teacher entrance has no password for normal use unless the password modal is enabled in the current UI.
- Student archive supports teacher/class/student structure.
- Teachers, classes, and students can be searched.
- Students and classes can be drag-moved and synced to the database.
- Teacher/class/student selection can be toggled closed by clicking again.
- Teachers can be hidden from the current frontend without deleting backend database data.
- Task queue supports creating, editing, deleting, and locating tasks.
- Task cards have `未开始` and `已结束` states.
- Finished tasks do not enter the pending correction list.
- Uploading correction images marks the task completed.
- Uploading student homework/answer files also marks the task completed.
- Any task with correction image, student uploaded homework/answer, or teacher note is treated as completed.
- If no correction image, no student homework/answer, and no teacher note exist, the task should be `未开始`.
- Teacher notes auto-save 3 seconds after the teacher stops typing.
- Assignment/correction images are compressed before upload to reduce resource point usage.
- Daily student feedback PDF can be generated by student and date.
- Feedback PDF should support Chinese text correctly.
- PDF generation uses caching to avoid repeated expensive generation.
- Teacher guide/manual is available in the site.
- Common file box and print queue support search, scrolling, download/delete where applicable.
- Print queue button/card was removed from the main metrics area; pending correction card was widened with red reminder text.
- Main dashboard uses a Three.js/interactive QLEDA curtain/fan visual background component.
- Teacher interface also has a smaller matching visual component.
- Teacher entry shows the `今日重点确认` todo list modal; the old red "task-table link update" notice modal was removed.
- Daily task check table replaced the old shared document area. It lets the user search/select a class, then open a full-screen daily check table.
- Daily check table columns include `list`, reading, listening, vocabulary CN/EN, speaking, writing, total.
- Daily check table supports task notes/header notes for each task column.
- Daily check table data is date-based; a new day has a separate table.
- Daily check tables are scoped by class: each teacher/class pair opens an independent table. The selector lists classes, while retaining the teacher name only as context.
- Existing same-day entries written under the former teacher-level scope are displayed in the matching student's class table; new writes use the actual class name.
- Task queue and daily check table are linked:
  - If a task title matches a daily check column label or that column's task note, the task and table entry are treated as the same item.
  - Only completion state and note are synced.
  - Other task fields, files, student archive, and class structure are not auto-modified by this link.
