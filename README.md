# QULEDA UpUp 使用说明

QULEDA UpUp 是一个给雅思机构内部使用的教学任务管理网站。

它主要解决这件事：老师布置任务，学生查看任务，老师或助教上传作业和批改结果，再把批改内容导出给家长。

## 1. 网站入口

网站打开后有两个入口：老师入口和学生入口。

老师入口需要密码：

```text
qleda123456
```

老师进入后可以管理学生、任务、文件、批改、打印队列和沟通消息。

学生进入后只能查看自己的档案、任务、作业和批改结果，不能修改任何内容。

## 2. 老师端功能

老师端顶部会显示几个关键数据：

- 学生数量
- 进行中任务
- 待批改任务
- 需要打印的文件数量

老师可以添加学生档案，填写姓名、年级、目标分、听力/阅读/写作/口语当前分数和分组。

老师可以删除学生。删除前会弹窗确认，确认后数据库也会同步删除。

老师可以新建任务，选择学生、填写标题和任务说明。

任务说明可以为空。

老师可以手动修改任务状态：未开始、进行中、已提交、已批改、已完成。

每个任务都可以上传作业文件，也可以上传批改后的照片。

批改照片一次最多上传 9 张，可以一次选择多张。

上传错的作业或批改照片都可以删除，删除后数据库同步更新。

老师可以给任务填写备注，备注可以为空。

老师可以点击“导出给家长”，把批改照片和老师评语导出成一张 PNG 长图。

如果没有上传批改照片，导出会失败，需要先上传图片格式的批改文件。

## 3. 打印队列

老师可以把需要打印的文件加入打印队列。

加入时可以填写打印份数、姓名或教室门牌号，也可以填写备注。

打印文件状态包括：待打印、已打印、已取消。

打印队列里的文件可以删除，删除后数据库同步更新。

## 4. 老师 / 助教沟通框

页面右侧有沟通框，可以让老师和助教简单留言。

发送消息时可以选择身份：老师或助教。

消息会保存到数据库。

新消息会自动显示在聊天框最下面。

每条消息右上角都有删除按钮，删除前会二次确认。

聊天框大小固定，消息多了只会在框内滚动，不会把页面撑长。

## 5. 学生端功能

学生端只能查看内容，不能修改内容。

学生可以查看：

- 自己的学生档案
- 自己的任务列表
- 任务状态
- 作业文件
- 批改照片
- 老师评语

学生不能添加、删除、上传、修改任务或修改档案。

## 6. 数据保存位置

数据库文件在：

```text
apps/api/data/qleda.sqlite
```

上传文件在：

```text
apps/api/data/uploads
```

主要数据包括学生档案、任务、作业文件、批改照片、打印队列、操作记录和聊天消息。

## 7. 本地启动

在项目根目录打开终端：

```text
C:\Users\admin\IdeaProjects\qleda_upup
```

第一次使用先运行：

```bash
npm install
npm run db:setup -w apps/api
```

以后启动网站运行：

```bash
npm run dev
```

浏览器打开：

```text
http://localhost:5173
```

如果页面提示后端不可用，请确认 `npm run dev` 正在运行。

如果提示 5173 端口被占用，说明之前的网站还没关，先关闭旧终端或旧进程后再启动。
